# 照片收件匣

照片放進 `photos-inbox/<地點名稱>/` 就好，例如 `photos-inbox/小油坑/`（HEIC、JPG、PNG 都可以）。
排程每 5 分鐘檢查一次，資料夾 2 分鐘沒變動後自動壓縮、上傳，約再過 2 分鐘網站就看得到。

- **說明（選填）**：同資料夾放 `說明.txt`，每行「原檔名 說明」，例如 `IMG_1234.HEIC 霧太大什麼都沒看到`。要寫說明請**先放說明再放照片**，或一起放
- **處理完**：整個資料夾移到 `_done/`（原圖保留，不會上傳）
- **沒處理**：資料夾裡會出現 `處理失敗.txt` 寫原因；常見是同名地點不只一個，把資料夾改成「`361 小油坑`」指定 id
- 地點要在網頁上標「已去過」，照片才會在「🧭 行程」分頁出現
- 紀錄：`logs/photo-sync.log`；手動立刻處理：`uv run scripts/add-photos.py`
