十天的奧捷跟團，長榮直飛維也納，先往西進湖區與薩爾茲堡，跨境到德國國王湖，再北上捷克：庫倫洛夫、卡羅維瓦利、布拉格，最後經潘朵芙 Outlet 回到維也納。

> **行程資訊**：長榮航空 BR065 去程（8/28 23:55 桃園起飛）、BR066 回程（9/5 12:30 維也納起飛，9/6 06:45 抵台）。住宿三晚五星：卡羅維瓦利溫泉飯店一晚、布拉格連住兩晚。

{{< day date="8/28" weekday="五" place="台北 → 維也納" imgs="" >}}
深夜從桃園機場出發，搭長榮 BR065 飛往維也納，夜宿機上。
{{< /day >}}

{{< day date="8/29" weekday="六" place="維也納 → 哈斯達特湖區 → 薩爾茲堡" imgs="" >}}
清晨抵達維也納，直接往西開進奧地利湖區（維也納 → 哈斯達特約 285km）。哈斯達特湖是湖區最幽靜、水溫最低的湖泊，小鎮列為 UNESCO 世界文化遺產。午餐吃湖區鱒魚料理。

午後前往薩爾茲堡（約 72km）：莫札特故居、米拉貝爾花園，也是電影《真善美》的拍攝地。

- 住宿：薩爾茲堡 4★ 飯店
{{< /day >}}

{{< day date="8/30" weekday="日" place="薩爾茲堡 → 國王湖 → 庫倫洛夫" imgs="" >}}
跨境到德國貝希特斯加登國家公園的國王湖（約 38km），冰河形成、德國最深的湖泊，搭遊船進湖。行程建議自費的貝希特斯加登鹽礦洞每人 €40。

下午進捷克，前往南波希米亞的庫倫洛夫（約 249km）：市政廳、城堡、橋廊、修道院玫瑰飯店。晚餐是百年地窖豬腳風味料理，夜宿小鎮內。

- 住宿：庫倫洛夫 OLD INN 或 MYLN 4★
- 小提醒：小鎮是石板路、大巴進不去，行李難拖，建議帶過夜包
{{< /day >}}

{{< day date="8/31" weekday="一" place="庫倫洛夫 → 卡羅維瓦利" imgs="" >}}
清晨在庫倫洛夫散步，之後開往巴洛克溫泉小鎮卡羅維瓦利（約 239km）。這裡「喝溫泉」比泡溫泉出名，沿著磨坊溫泉迴廊、莎多瓦溫泉迴廊、德弗札克公園走一圈。午餐是捷式烤雞。

- 住宿：卡羅維瓦利溫泉區 5★ 飯店
{{< /day >}}

{{< day date="9/1" weekday="二" place="卡羅維瓦利 → 布拉格" imgs="" >}}
前往布拉格（約 128km），午餐是米其林推薦餐廳。接著走舊城區：查理士大橋、老城廣場、火藥塔。

- 住宿：Grand Hotel Prague Towers 5★（連住兩晚）
{{< /day >}}

{{< day date="9/2" weekday="三" place="布拉格" imgs="" >}}
上午參觀布拉格古堡皇宮區：聖維塔大教堂、黃金小巷（卡夫卡住過的 22 號）。中午搭伏爾塔瓦河遊船吃午宴，另外安排電車體驗。下午自由活動。行程建議自費的黑光劇每人 €40。
{{< /day >}}

{{< day date="9/3" weekday="四" place="布拉格 → 潘朵芙 Outlet → 維也納" imgs="" >}}
長途南下（布拉格 → 潘朵芙約 367km），到奧地利最大的潘朵芙購物村 Parndorf Outlet 逛街，之後前往維也納。行程建議自費的維也納音樂會每人 €90。

- 住宿：維也納 4★ 飯店（連住兩晚）
{{< /day >}}

{{< day date="9/4" weekday="五" place="維也納" imgs="" >}}
維也納市區一日：熊布朗宮（入內）、霍夫堡宮、瑪麗亞特蕾莎廣場、百水公寓、聖史蒂芬大教堂、施華洛世奇水晶旗艦店。午餐吃維也納豬肋排與沙河蛋糕。
{{< /day >}}

{{< day date="9/5" weekday="六" place="維也納 → 台北" imgs="" >}}
中午從維也納機場搭長榮 BR066 回台，夜宿機上。
{{< /day >}}

{{< day date="9/6" weekday="日" place="抵達台北" imgs="" >}}
清晨 06:45 抵達桃園機場，結束十天的奧捷之旅。
{{< /day >}}
